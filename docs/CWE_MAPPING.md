# Appendix B — CWE Reference & Classification Mapping
**Project Unit42-FirmwareX | Palo Alto Networks — Unit 42**

This document specifies the exact Common Weakness Enumeration (CWE) classification matrix implemented within the Unit42-FirmwareX analysis engine.

---

## 1. Weakness Mapping Table

| CWE ID | Common Name | Trigger / Indicator in Embedded Firmware | Primary Detection Stage | Risk Rating |
| :--- | :--- | :--- | :--- | :--- |
| **CWE-120** | Buffer Copy without Checking Size | Unbounded string copy or buffer manipulation via `strcpy`, `strcat`, `gets`, or unconstrained `sprintf`. | Static Audit & Taint Analysis | **High** |
| **CWE-121** | Stack-based Buffer Overflow | Symbolic constraint solving proves user input length exceeds local stack frame allocation, corrupting saved frame pointer or return address (`$ra`, `lr`, `rip`). | Bounded Symbolic Execution | **Critical** |
| **CWE-122** | Heap-based Buffer Overflow | Dynamic allocation (`malloc`/`calloc`) followed by unbounded copy into heap chunk boundaries. | Symbolic / Dynamic Emulation | **High** |
| **CWE-787** | Out-of-bounds Write | Memory copy routines (`memcpy`, `memmove`) writing data past target structure boundaries without pointer validation. | Static Audit & Symbolic Engine | **High / Medium** |
| **CWE-134** | Use of Externally-Controlled Format String | User input passed directly as format specifier to `printf`, `sprintf`, `syslog`, or `snprintf` without format token (`%s`). | Static Sinks & Taint Tracking | **High** |
| **CWE-78** | Improper Neutralization of Special Elements used in an OS Command ('OS Command Injection') | Attacker-controlled parameters (HTTP query params, NVRAM variables, CLI flags) concatenated into `system()`, `popen()`, `execl()`, or `execve()` strings. | Taint Flow Analysis | **Critical** |

| **CWE-1277** | Firmware Not Updateable / Missing Hardening | Absence of basic exploit mitigations: Non-Executable stack (NX/DEP), Position Independent Executables (PIE/ASLR), stack canaries, or full RELRO. | Checksec Hardening Scanner | **Medium / Low** |

## 2. Confidence Calibration

Every vulnerability finding generated by Unit42-FirmwareX carries a calibrated confidence level:
1. **`confirmed`**:
   - The finding was verified through dynamic symbolic constraint satisfaction, memory corruption simulation, or verified taint reachability to dangerous sinks.
2. **`probable`**:
   - Discovered through direct data flow correlation where inputs reach dangerous sinks, but path constraints were solved with heuristic approximations.
3. **`heuristic`**:
   - Statically identified leads, such as presence of banned C runtime symbols in the ELF symbol table without a verified runtime trace.

---

## 3. Redaction and Non-Weaponization Guarantees

All findings matching `CWE-798`, `CWE-259`, and `CWE-321` are subjected to **100% Redaction**:
- Plaintext credentials and tokens are immediately masked (`AKIA************MPLE`).
- A deterministic SHA-256 fingerprint is recorded (`sha256:<hash>`) to enable deduplication and triage without exposing sensitive material.
- Crash states are reported strictly as diagnostic register dumps (`$pc`, `$ra`, `$sp`, offset), never as working exploit payloads, shellcode, or weaponized PoCs.
